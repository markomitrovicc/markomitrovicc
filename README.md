## 🚀 Projects

### Jobs API
A **simple Express.js API** implementing:  
- CRUD operations  
- JWT authentication  
- CORS  
- XSS protection  
- Rate limiting  
- Password hashing with Bcrypt  

### Northpeak Store Frontend (store-frontend)
An **Angular storefront** for a full-stack outdoor gear e-commerce application.

- Product catalog with search, category, brand, and price filters
- Product detail pages and stock-aware cart actions
- Cookie-based authentication and session restoration
- Authenticated cart, order history, order details, and user profile
- Admin-only product creation, editing, and deletion
- Light / dark theme toggle
- Lazy-loaded routes and Angular standalone components
- Unit testing with Vitest

**Tech stack:** Angular 21, TypeScript, Tailwind CSS 4, RxJS, Vitest

**Live demo:** https://store-frontend-peach.vercel.app/

### Web Shop API (nest-store-api)
A **NestJS backend** powering the Northpeak Store frontend with product catalog, authentication, cart, and order management.

- REST API with product search, filtering, and pagination
- Authentication with Better Auth and cookie-based sessions
- User session and profile management
- Authenticated shopping cart with stock validation
- Checkout and order management with product snapshots
- Admin-only product creation, updating, and deletion
- API documentation with Swagger
- Security with Helmet, CORS, and rate limiting
- MongoDB database with Mongoose
- Deployed to Render

**Tech stack:** NestJS 11, TypeScript, MongoDB, Mongoose, Better Auth, Swagger, Helmet

**API:** https://nest-store-api-1.onrender.com/  
**Swagger:** https://nest-store-api-1.onrender.com/api
